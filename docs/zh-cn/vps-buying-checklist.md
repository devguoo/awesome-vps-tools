# VPS 购买前检查清单

这份清单给中文用户做 VPS、海外云服务器或托管主机购买前核对用。重点不是推荐某一家服务商，而是先把用途、访问区域、预算、管理能力、账单和备份想清楚，再进入具体服务商页面。

## 先回答 6 个问题

| 问题 | 为什么要先确认 |
|---|---|
| 服务器准备用来做什么？ | 学 Linux、建站、WordPress、外贸站、备用节点、监控或正式业务，对配置和管理要求不同。 |
| 用户主要在哪个地区？ | 访问区域决定机房、线路、延迟、丢包和 CDN 方案。 |
| 你能不能自己维护 Linux？ | 自管 VPS 便宜但要自己处理 SSH、安全、备份、更新和故障。 |
| 更在意价格还是稳定省心？ | 低价 VPS、线路型 VPS、托管 WordPress 主机解决的问题不一样。 |
| 账单是否看懂了？ | 月付、年付、续费、流量、备份、附加服务和税费都会影响长期成本。 |
| 有没有替代方案？ | 热门套餐可能缺货，优惠可能失效，付款方式也可能临时不适合。 |

## 不要只看价格

购买前至少同时看这些因素：

- 套餐系列和定位；
- CPU、内存、硬盘、带宽和月流量；
- 机房和目标用户距离；
- 当前是否有货；
- 付款周期和续费压力；
- 退款、取消、升级和迁移规则；
- 你是否有备份、安全和监控方案。

低价本身不是问题，但如果没有备份、不会排障、不了解账单，便宜服务器也可能变成更高的时间成本。

## 自管 VPS 和托管主机的区别

| 类型 | 你需要负责 | 更适合谁 |
|---|---|---|
| 自管 VPS | SSH、系统更新、防火墙、备份、监控、Web 环境、故障排查。 | 想学习 Linux、需要灵活控制、能接受自己维护的人。 |
| 托管 WordPress 主机 | 大部分服务器维护由平台处理，但价格通常更高、平台限制更多。 | 主要做 WordPress，希望减少维护时间的人。 |
| 类 Cloudways 平台 | 需要选择云厂商、配置和地区，但管理面板会降低维护难度。 | 想比传统托管更灵活，又不想完全自管服务器的人。 |

## 付款前最后核对

1. 价格是否是最终结账页显示的金额。
2. 优惠码是否真的在结账页生效。
3. 付款周期是否适合长期使用。
4. 目标套餐是否有货。
5. 所选机房是否适合你的主要用户。
6. 备份和安全措施是否准备好。
7. 如果买错，是否知道退款、取消或迁移方式。
