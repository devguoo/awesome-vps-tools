## 中文用户常见判断顺序

1. 先确认用途：学习、建站、跨境访问、长期项目、备用节点还是托管 WordPress。
2. 再确认访问区域：主要用户在中国大陆、香港、日本、新加坡、美国还是全球。
3. 看预算和付款周期：不要只看首月价格，也要看续费和长期成本。
4. 核对线路、机房、库存、流量、带宽和备份能力。
5. 最后进入具体服务商购买页，确认最终价格、优惠、退款和服务条款。

## 购买前提醒

- 不要只看最低价，线路、机房、库存、流量和续费成本同样重要。
- 不要把 GitHub 工具仓库当成服务商最终价格页，最终金额以官方结账页显示为准。
- 不要在公开 issue、评论或 benchmark 里贴自己的账号、服务器 IP、后台截图、API Key 或订单信息。
- 如果你只是在找工具清单，可以继续看英文工具目录：[VPS tools directory](../)。
