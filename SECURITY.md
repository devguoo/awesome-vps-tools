# Security Policy

## Reporting Sensitive Information

If you find exposed credentials, API keys, tokens, private account data or personal information in this repository, do not post the secret in a public issue. Report it privately through GitHub's security reporting features if available, or contact the maintainer through the GitHub profile.

## Repository Safety Rules

- Do not submit `.env` files, private keys, API tokens, credentials or screenshots of private dashboards.
- Do not add links that require users to share credentials with unknown services.
- Example configuration must use fake values such as `YOUR_API_KEY_HERE`.
- Affiliate-only pages and thin promotional pages are not accepted.

This repository is a curated resource list. It should not require users to provide private data.
