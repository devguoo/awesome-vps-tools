# Code of Conduct

## Our Standard

Please keep contributions respectful, factual and useful. This repository is a curated technical resource for VPS and server-management tools.

Encouraged behavior:

- Suggest high-quality tools with clear documentation.
- Explain why an entry is useful.
- Point out broken links or unmaintained projects.
- Keep descriptions factual and concise.

Unacceptable behavior:

- Harassment, insults or discriminatory language.
- Spam, link dumping or repeated self-promotion.
- Posting credentials, personal information or private account data.
- Misleading claims about official status, guaranteed performance or guaranteed pricing.

Maintainers may edit, close or remove content that does not follow these standards.
